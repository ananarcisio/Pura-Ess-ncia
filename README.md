# 🌿 Pura Essência | Cosméticos Naturais

> **Uma interface elegante, moderna e responsiva para um e-commerce premium de cosméticos naturais, veganos e cruelty-free.**

O **Pura Essência** é um projeto de front-end focado na excelência de **UX (User Experience) e UI (User Interface)**. Ele unifica a experiência de compra em uma **Single Page Application (SPA)** leve e de alta performance, utilizando janelas modais fluidas e navegação com rolagem suave (*smooth scroll*) para manter o usuário sempre imerso no contexto da marca. Desenvolvido em prol da disciplina de Front-End.

---
## ✨ Funcionalidades

* ⚡ **Single Page Application (SPA):** Navegação fluida e instantânea sem recarregamento de página.
* 📱 **Design Responsivo:** Adaptado perfeitamente para smartphones, tablets e desktops.
* 📱 **Sistema de Modais:** Login e cadastro integrados de forma dinâmica na mesma tela.
* 🔔 **Toast Notifications:** Alertas interativos e modernos que substituem o `alert()` nativo do navegador.
* 🛍️ **Galeria de Produtos:** Cards interativos com efeitos de *hover* e elementos visuais atraentes.
* 🍔 **Menu Mobile Inteligente:** Navegação otimizada e acessível para dispositivos móveis.
* 📩 **Formulário de Contato:** Seção de atendimento integrada diretamente na página inicial.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web puras e bibliotecas via CDN, garantindo simplicidade e velocidade na inicialização do ambiente de desenvolvimento:

* **HTML5:** Estruturação semântica para melhor acessibilidade e SEO.
* **Tailwind CSS (via CDN):** Estilização utilitária com um *design system* customizado (tons pastéis e tipografia premium).
* **JavaScript Vanilla:** Lógica pura para controle de modais, menus, toasts e interações da loja.
* **Phosphor Icons:** Biblioteca de ícones moderna, leve e minimalista.
* **Google Fonts:** Tipografia refinada utilizando *Playfair Display* (títulos) e *Inter* (corpo de texto).

## 🛠️ Como Executar o Projeto

Como o projeto não possui gerenciadores de pacotes ou dependências complexas, a execução é extremamente simples:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/pura-essencia.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd pura-essencia
   ```

3. **Inicie o projeto:**
   * Abra o arquivo `index.html` diretamente no seu navegador, **ou**
   * Clique com o botão direito no `index.html` e selecione **Open with Live Server** no VS Code para suporte a *Hot Reload*.
